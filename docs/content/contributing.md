# Contributing

TcKit is developed on GitHub. The full contribution guide — adapter and port recipes, code style, local commands, skills, and the PR workflow — lives in [CONTRIBUTING.md](https://github.com/georgeturneruk/tckit/blob/main/CONTRIBUTING.md) in the repo root.

For the source tree and the port-method reference table, see [Architecture Overview](architecture/overview.md).

Spotted something in these docs that needs fixing? The pencil edit icon at the top right of every page links straight to the source on GitHub.
